# Pratik Priyadarshi Swain - Personal Portfolio (React + Vite)

A modern, responsive, and recruiter-focused portfolio web application built with **React 18** and **Vite** for **Pratik Priyadarshi Swain**, a second-year Computer Science Engineering student at GIET University, Gunupur, aspiring to become a Web Developer and Software Engineer.

---

## ⚡ Highlights & Features

- **React 18 & Vite**: Lightning-fast developer experience, modern component architecture, and optimized production bundle.
- **Pure Vanilla CSS Design System**: Preserves all custom CSS design tokens, glowing gradient accents, glassmorphism, fluid typography, and dark/light mode toggle.
- **Recruiter-Friendly Structure**:
  - **Navbar**: Accessible skip-link, desktop & mobile drawer menu, dynamic scroll spy, and theme toggle.
  - **Hero**: Second-Year CSE student badge, quick metrics, social links, and one-click email copy button.
  - **About**: Transparent second-year background, career objective, team value-add points, and 7 core soft skills cards.
  - **Skills**: React state-driven category filtering covering C, Java, HTML5, CSS3, JavaScript, Spring Boot, MySQL, Git, and GitHub.
  - **Featured Project**: Spotlight on *Automated Resume Screener & Skill-Matcher* with an interactive deep-dive architecture modal.
  - **Education**: Detailed academic timeline (GIET University 1st Year B.Tech, 12th CHSE Odisha, 10th BSE Odisha).
  - **Achievements & Certifications**: Transparent section stating that verified certifications, workshops, and hackathons will be added upon completion.
  - **Contact**: Direct email copy button, verified LinkedIn & GitHub links, and client-validated message form with mailto integration.
- **Accessibility**: Keyboard navigable (Escape key handling for modals and mobile menu), ARIA attributes, skip-link, and high-contrast indicators.

## 🚀 How to Run Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open your browser and visit the local server URL (typically `http://localhost:5173`).

### 3. Build for Production
```bash
npm run build
```
